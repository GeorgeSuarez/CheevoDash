# Remove the Achievement Progress Over Time chart and its pipeline

The Achievement Progress Over Time chart (`achievement-chart.tsx`) was orphaned during the July 2026 dashboard reshuffles — nothing rendered it, yet `DashboardData` still carried `friends`, `comparison`, and `achievementSeries`, two API routes (`/api/community-trend`, `/api/friends-comparison`), the `global_game_snapshots` table with its nightly cron loop, and `lib/series.ts` all existed solely to feed it. We decided to delete the whole dead surface rather than keep it dormant: the three `DashboardData` fields, both routes, the chart component, `getFriendsComparison`, `lib/series.ts`, the `global_game_snapshots` table (drop migration `0003`), and the `recharts` dependency. The `range` dimension (7d/30d/90d/1y) was purged along with it — it only ever varied the series, so the Range selector and the `defaultRange` preference were behaviorless (column dropped in migration `0004`).

- **Rejected: keep the pipeline dormant.** We considered keeping `global_game_snapshots` and `series.ts` so the chart could be revived later. Rejected on YAGNI: pass-through complexity with no caller, and git history preserves it. A future chart should be built against the live per-game data (`Game.unlocktimes`, `game.comparison`), which still exists.
- **Rejected: keep the Range selector as a no-op UI.** A selector that changes nothing is worse than no selector; `filter` remains the only live dimension.
- **Still live:** user snapshots (`snapshots` table, `avgCompletionDelta`/`gamesOwnedDelta`) and per-game community comparison (`game.comparison`, rendered by `top-games.tsx`) are unrelated and retained.
